# Original Astra archive

This directory preserves the original manuscript and proof artifacts
generated through Karthik Sethuraman's iterations with GPT-6 Astra over
several weeks, imported into this repository on September 11, 2026.

The contents were formerly under `artifacts/`:

- [Original review manuscript](wilf_four_generators_review_manuscript_2026-09-11.md).
- [Original review package](wilf_four_generators_review_package_2026-09-11/README.md),
  including earlier rounds, exploratory computations, and historical outputs.

The original proof files are unchanged. Finder metadata has been omitted.
Internal descriptions such as “current,” “canonical,” and “retained” refer
to the state of the original Astra work, not the present paper.

The current argument is in [manuscript/](../manuscript/README.md), and its
computational companion is in [verification/](../verification/README.md).
Neither depends on this archive. Subsequent reconstruction notes and
superseded checking paths are preserved separately in Git history.
